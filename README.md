食品安全抽检数据分析项目（大一实战）

项目简介
作为一名食品质量与安全专业的大一新生，我利用 Python 对某省市场监督管理局公开的食品安全抽检数据进行了清洗、分析和可视化。

技术栈
· Python (Pandas, Matplotlib)
· 数据清洗（正则表达式提取、长文本拆分）
· 数据可视化

主要发现
通过分析几千条抽检数据，发现该省本次抽检中，噻虫胺（农药残留）和过氧化值（油脂酸败）是排名前两位的高频不合格项目。

文件说明
· analyze.ipynb：完整的分析代码（包含合格与不合格数据的处理）
· chart_top10.png：不合格项目 Top 10 可视化图表
· shipinhege.xlsx / shipinbuhege.xlsx：原始数据
